# 3-3. 配置專案設定檔

## 描述

根據架構設計，配置 Docusaurus 專案的核心設定檔案，包括網站基本資訊、GitHub Pages 部署參數、內容路徑配置、中英文搜尋功能等。此步驟是確保應用程式倉庫能正確讀取內容倉庫內容並生成靜態網站的關鍵配置。

## 工項 tasks

- [ ] 3-3-1. 設定 `docusaurus.config.js`
  - [ ] 配置網站基本資訊 (title, tagline, url)
  - [ ] 設定 GitHub Pages 部署參數
  - [ ] 配置內容路徑指向 `./content/`
  - [ ] 啟用中英文搜尋功能
- [ ] 3-3-2. 設定 `sidebars.js` 側邊欄結構
- [ ] 3-3-3. 更新 `package.json` 腳本與依賴

## 測試方式

執行以下測試驗證設定檔案配置正確：

1. **基本建置測試**：
   ```bash
   cd /home/debian/whyblog-docusaurus/docusaurus
   npm run build
   ```
   確認建置過程無錯誤，生成 `build` 目錄

2. **本地開發伺服器測試**：
   ```bash
   npm run start -- --host 0.0.0.0 --port 3000
   ```
   訪問 `http://localhost:3000` 確認網站正常運行

3. **內容路徑驗證**：
   - 確認可正確讀取 `./content/blog/` 下的部落格文章
   - 確認可正確讀取 `./content/docs/` 下的文件頁面
   - 驗證 `./content/static/img/` 下的圖片資源可正確載入

4. **搜尋功能測試**：
   - 在本地環境中測試中文關鍵字搜尋
   - 測試英文關鍵字搜尋
   - 確認搜尋結果能正確顯示

5. **GitHub Pages 配置驗證**：
   ```bash
   # 檢查設定檔中的部署參數
   grep -A 5 -B 5 "github.io\|deploymentBranch\|organizationName\|projectName" docusaurus.config.js
   ```
