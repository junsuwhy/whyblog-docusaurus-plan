# 3-4. 配置導航結構檔案

## 描述

配置 Docusaurus 網站的導航結構，包括頂部導航欄、側邊欄、頁腳連結，以及設定網站為台灣繁體中文語系。此任務將建立完整的網站導航體驗，確保使用者能夠輕鬆瀏覽部落格、文件和其他頁面內容。

## 工項 tasks

- [ ] 設定頂部導航欄 (navbar) - 首頁、部落格、文件、關於
- [ ] 配置 `sidebars.js` 側邊欄結構 - 按主題分類文件
- [ ] 設定頁腳連結與社群媒體連結
- [ ] 配置麵包屑導航顯示
- [ ] 網站改設定成預設語言用台灣繁體中文，不用簡體中文。第二語言用英語

## 測試方式

執行以下指令來驗證任務是否成功完成：

1. **啟動開發伺服器測試**：
   ```bash
   cd /home/debian/whyblog-docusaurus/docusaurus
   npm run start -- --host localhost
   ```

2. **驗證導航結構**：
   - 訪問 `http://localhost:3000` 確認首頁可正常載入
   - 確認頂部導航欄包含：首頁、部落格、文件、關於等選項
   - 確認側邊欄在文件頁面正確顯示，且結構清晰
   - 確認頁腳連結正常顯示
   - 確認麵包屑導航在適當頁面正確顯示

3. **驗證語系設定**：
   - 確認網站介面顯示為台灣繁體中文
   - 確認預設文字（如"部落格"、"文件"等）為繁體中文
   - 確認搜尋功能支援中英文

4. **檢查設定檔案**：
   - 確認 `docusaurus.config.js` 中的 navbar 設定正確
   - 確認 `sidebars.js` 檔案結構合理且路徑正確
   - 確認語系設定 (i18n) 已正確配置為 `zh-Hant`

5. **建置測試**：
   ```bash
   npm run build
   ```
   確認建置過程無錯誤，且生成的網站包含正確的導航結構
