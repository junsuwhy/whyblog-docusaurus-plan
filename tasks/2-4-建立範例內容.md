# 2-4. 建立範例內容

## 描述

建立部落格和知識庫的範例內容，包括歡迎文章、入門文件和測試用圖片資源，為後續的系統整合測試提供基礎內容。

## 工項 tasks

- [ ] 檢查是否已有文章，沒有則撰寫歡迎部落格文章
- [ ] 檢查是否已有文章，沒有則建立入門文件頁面
- [ ] 檢查是否已有資源，沒有則準備測試用圖片資源

## 測試方式

請驗證以下項目已成功建立：
1. 檢查 `blog/` 目錄是否包含歡迎文章
2. 檢查 `docs/` 目錄是否包含入門文件
3. 檢查 `img/` 目錄是否包含測試用圖片
4. 確認所有內容格式符合 Docusaurus 標準

## 完成流程

請在 3.tasks.md 本項 task 的 [ ] 打上 [x] 記號表示完成，打上 [?] 記號表示尚有待處理、之後再檢查事項。
做記號完後在 task 的「目前任務」更新到下一個任務
清除執行記憶
讀取並執行 prompt-003-create-each-task.txt
