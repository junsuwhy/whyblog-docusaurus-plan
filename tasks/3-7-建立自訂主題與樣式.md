# 3-7. 建立自訂主題與樣式

## 描述

為 Docusaurus 網站建立自訂的視覺主題與樣式系統，包含自訂 CSS 樣式、響應式佈局設計，以及必要的 React 元件。此任務將確保網站具有專業且一致的視覺呈現，並提供良好的使用者體驗。

## 工項 tasks

- [ ] 設定 `src/css/custom.css` 自訂樣式
  - [ ] 定義主要色彩方案（主色、輔色、文字色彩）
  - [ ] 設定字型系統（中文支援、階層結構）
  - [ ] 配置間距系統與版面配置變數
  - [ ] 自訂導航欄樣式
  - [ ] 設定側邊欄與內容區域樣式
  - [ ] 配置按鈕、連結等互動元素樣式
- [ ] 建立必要的 React 元件 (如有需要)
  - [ ] 檢查是否需要自訂首頁元件
  - [ ] 評估是否需要自訂頁腳元件
  - [ ] 建立任何特殊功能元件（如 CTA 按鈕、特色區塊）
- [ ] 設計響應式佈局
  - [ ] 確保所有樣式在桌面版本正常顯示
  - [ ] 優化平板電腦顯示效果（768px-1024px）
  - [ ] 調整手機版本佈局（小於 768px）
  - [ ] 測試導航選單在不同螢幕尺寸的表現
  - [ ] 驗證內容區域的響應式表現

## 測試方式

請執行以下驗證步驟確認任務完成：

### 1. 本地開發伺服器測試
```bash
cd /home/debian/whyblog-docusaurus/docusaurus
npm start -- --host 0.0.0.0
```
在瀏覽器訪問 `http://localhost:3000` 檢查：
- 自訂樣式是否正確載入
- 頁面整體視覺效果是否符合預期
- 導航與側邊欄樣式是否正常

### 2. 響應式設計測試
使用瀏覽器開發者工具測試不同螢幕尺寸：
- 桌面版（1920x1080, 1366x768）
- 平板版（768x1024, 1024x768）
- 手機版（375x667, 414x896）

### 3. 建置測試
```bash
npm run build
```
確認建置過程無錯誤，且生成的靜態檔案包含自訂樣式。

### 4. 樣式一致性檢查
檢查以下頁面的視覺一致性：
- 首頁
- 部落格頁面
- 文件頁面
- 個別文章/文件頁面

### 5. 跨瀏覽器相容性
在主要瀏覽器測試：Chrome, Firefox, Safari, Edge
