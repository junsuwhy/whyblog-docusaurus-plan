# 3-5. 更新專案依賴與腳本

## 描述

更新 Docusaurus 專案的依賴套件版本，確保所有必要的建置與開發腳本正確配置，並安裝搜尋套件依賴。此任務需要檢查 package.json 中的套件版本，新增必要的腳本命令，並配置本地開發伺服器的主機參數。

## 工項 tasks

- [ ] 檢查並更新 `package.json` 中的 Docusaurus 版本
- [ ] 新增必要的建置腳本 (build, start, serve)
- [ ] 安裝並配置搜尋套件依賴
- [ ] 設定本地開發伺服器參數 (host: 'localhost')

## 測試方式

執行以下指令驗證任務完成：

1. **檢查套件版本**：
   ```bash
   cd /home/debian/whyblog-docusaurus/docusaurus
   npm list @docusaurus/core @easyops-cn/docusaurus-search-local
   ```

2. **驗證建置腳本**：
   ```bash
   npm run build
   npm run start --help
   npm run serve --help
   ```

3. **測試本地開發伺服器**：
   ```bash
   npm run start -- --host localhost
   # 應該能在該主機上啟動開發伺服器
   ```

4. **檢查依賴安裝**：
   ```bash
   npm install
   # 應該能成功安裝所有依賴，無錯誤或警告
   ```

5. **驗證搜尋套件配置**：
   - 檢查 `package.json` 包含 `@easyops-cn/docusaurus-search-local`
   - 檢查 `docusaurus.config.js` 中的 themes 配置正確
