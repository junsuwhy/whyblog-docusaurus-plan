# 1-1. 建立 GitHub 組織或確認個人帳號設定

## 描述

此任務是 Blog-KnowledgeBase-v1 專案的第一步，需要準備適當的 GitHub 環境來支持雙倉庫架構。確保擁有必要的權限來建立兩個倉庫（內容倉庫和應用程式倉庫），並設定跨倉庫的自動化觸發機制。

## 工項 tasks

- [ ] 評估是否需要建立 GitHub 組織或使用個人帳號
- [ ] 確認帳號具備建立 public repositories 的權限
- [ ] 驗證帳號可以使用 GitHub Actions 功能
- [ ] 確認可以建立 Personal Access Tokens
- [ ] 檢查 GitHub Pages 功能是否可用
- [ ] 準備兩個倉庫的命名計劃（為下一個任務做準備）

## 測試方式

- 在 GitHub 介面中能夠看到「New repository」按鈕
- 能夠訪問 Settings > Developer settings > Personal access tokens
- 能夠訪問帳號或組織的 Actions 設定頁面
- 確認帳號沒有被限制使用 GitHub Pages 功能
- 能夠建立測試用的 public repository（可選，用於驗證後刪除）

## 完成流程

請在 3.tasks.md 本項 task 的 [ ] 打上 [x] 記號表示完成，打上 [?] 記號表示尚有待處理、之後再檢查事項。
做記號完後在 task 的「目前任務」更新到下一個任務
