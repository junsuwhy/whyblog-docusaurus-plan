# 3-6. 建立內容結構對應

## 描述

驗證並建立 Docusaurus 應用程式與內容倉庫之間的正確對應關係，確保內容目錄結構與應用程式設定檔案完全匹配，並測試所有靜態資源能正確載入。此步驟是連接內容與應用程式的關鍵橋樑，必須確保雙倉庫架構中的內容路徑對應無誤。

## 工項 tasks

- [ ] 驗證 content/docs 目錄結構與 sidebars.js 對應
  - [ ] 檢查 docusaurus/sidebars.js 中定義的路徑是否對應實際的 content/docs 結構
  - [ ] 確認側邊欄分類與實際文檔目錄一致
  - [ ] 驗證文檔 ID 與檔案路徑的正確對應
- [ ] 確認 content/blog 目錄與部落格設定匹配
  - [ ] 檢查 docusaurus.config.js 中 blog.path 設定是否正確指向 './content/blog'
  - [ ] 驗證部落格文章的日期目錄結構符合 Docusaurus 規範
  - [ ] 確認部落格文章的 frontmatter 格式正確
- [ ] 檢查 content/blog/authors.yml 格式正確性
  - [ ] 驗證 authors.yml 的 YAML 語法正確性
  - [ ] 確認作者資料結構符合 Docusaurus 規範（name, title, url, image_url 等欄位）
  - [ ] 測試作者資料在部落格文章中的正確顯示
- [ ] 測試靜態資源路徑 (images, files) 正確載入
  - [ ] 檢查 content/static/img 目錄中的圖片資源
  - [ ] 驗證 Markdown 文件中的圖片引用路徑正確
  - [ ] 測試靜態檔案在本地開發伺服器的載入狀況
  - [ ] 確認資源路徑在生產環境的正確性

## 測試方式

執行以下指令和檢查來驗證任務完成：

1. **檢查目錄結構對應**：
   ```bash
   cd docusaurus
   ls -la content/
   ls -la content/docs/
   ls -la content/blog/
   cat sidebars.js
   ```

2. **驗證設定檔案**：
   ```bash
   cd docusaurus
   node -e "console.log(JSON.stringify(require('./docusaurus.config.js').presets[0][1], null, 2))"
   ```

3. **檢查 authors.yml 語法**：
   ```bash
   cd docusaurus
   node -e "const yaml = require('js-yaml'); const fs = require('fs'); try { const doc = yaml.load(fs.readFileSync('./content/blog/authors.yml', 'utf8')); console.log('YAML 語法正確:', JSON.stringify(doc, null, 2)); } catch (e) { console.error('YAML 語法錯誤:', e.message); }"
   ```

4. **測試本地開發伺服器**：
   ```bash
   cd docusaurus
   npm start -- --host localhost --port 3000
   # 在瀏覽器開啟 http://localhost:3000
   # 檢查：
   # - 首頁是否正常顯示
   # - 部落格頁面是否能看到文章
   # - 文件頁面是否能正常導航
   # - 圖片資源是否正確載入
   # - 作者資訊是否正確顯示
   ```

5. **驗證建置流程**：
   ```bash
   cd docusaurus
   npm run build
   npm run serve -- --host localhost --port 3000
   # 確認生產版本也能正常運行
   ```
