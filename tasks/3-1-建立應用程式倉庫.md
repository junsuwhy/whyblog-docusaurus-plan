# 3-1. 建立應用程式倉庫 (App Repository)

## 描述

建立專用於 Docusaurus 應用程式的 GitHub 倉庫，此倉庫將負責：
1. 接收來自內容倉庫的 repository_dispatch 事件觸發
2. 自動檢出內容倉庫的最新內容
3. 執行 Docusaurus 建置流程
4. 部署靜態網站至 GitHub Pages

這個倉庫是整個雙倉庫架構中的應用程式端，負責將內容轉換為可訪問的網站。

## 工項 tasks

- [x] 在 GitHub 建立新的公開倉庫 `whyblog-docusaurus`
- [x] 設定倉庫描述為 "Docusaurus-based blog and knowledge base application"
- [x] 啟用 GitHub Pages 功能
- [x] 配置 GitHub Pages 使用 GitHub Actions 作為來源
- [x] 設定倉庫的基本設置 (Issues、Wiki、Projects 等)
- [ ] 建立初始的 README.md 文件說明專案用途
- [x] 設定倉庫主題標籤 (topics): docusaurus, blog, knowledge-base, github-pages
- [x] 配置 repository settings 中的 Actions permissions
- [ ] 準備後續 Docusaurus 專案初始化的環境

## 測試方式

請驗證以下項目確認任務完成：
1. 訪問 GitHub 上的 `whyblog-docusaurus` 倉庫確認已成功建立
2. 確認倉庫為公開 (public) 狀態
3. 確認 GitHub Pages 功能已啟用
4. 確認 Settings > Pages 中已設定使用 "GitHub Actions" 作為來源
5. 確認 Settings > Actions > General 中已設定適當的權限
6. 確認倉庫有適當的描述和標籤
7. 確認可以正常進行 git clone 操作
