# 2-1. 建立內容倉庫 (Content Repository)

## 描述

建立專門存放部落格文章和知識庫內容的 GitHub 倉庫，作為雙倉庫架構中的內容倉庫。此倉庫將負責存放 Markdown 文件、圖片等靜態資源，並透過 repository_dispatch 機制觸發應用程式倉庫的自動建置與部署。

## 工項 tasks

- [x] 在 GitHub 建立新的 public 倉庫，命名為 `whyblog-content`
- [x] Clone 該倉庫到本機，目錄為 `whyblog-docusaurus/content`
- [ ] 在目錄建立初始的 README.md，說明倉庫用途和結構
- [ ] 建立初始 Commit
- [ ] 驗證倉庫可以被應用程式倉庫存取

## 測試方式

請透過以下方式驗證任務已成功：
1. 確認 GitHub 上存在名為 `whyblog-content` 的 public 倉庫
2. 驗證倉庫有適當的 README.md 和描述
3. 檢查倉庫的 Actions 權限設定是否正確配置
4. 確認倉庫結構清晰，為後續內容添加做好準備
