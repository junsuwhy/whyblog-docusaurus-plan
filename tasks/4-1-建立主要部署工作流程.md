# 4-1. 建立主要部署工作流程

## 描述

建立 GitHub Actions 的主要部署工作流程，實現雙倉庫架構中應用程式倉庫的自動化部署功能。此工作流程將監聽內容倉庫的 repository_dispatch 事件，自動檢出內容，建置 Docusaurus 網站，並部署到 GitHub Pages。

此任務的核心是建立 `.github/workflows/deploy.yml` 檔案，整合整個自動化部署流程，包括內容同步、環境設定、依賴安裝、建置執行與頁面部署。

## 工項 tasks

- [ ] 建立 `.github/workflows/deploy.yml` 檔案
- [ ] 配置 repository_dispatch 事件監聽 (event-type: content-updated)
- [ ] 設定工作流程權限 (contents: read, pages: write, id-token: write)
- [ ] 建立並行處理工作 (build job 與 deploy job)
- [ ] 設定內容倉庫檢出步驟 (使用 CONTENT_REPO_TOKEN)
- [ ] 配置 Node.js 18 環境與 npm 快取設定
- [ ] 設定依賴安裝步驟 (`npm ci`)
- [ ] 配置 Docusaurus 建置流程 (`npm run build`)
- [ ] 設定 GitHub Pages 相關步驟 (configure-pages, upload-pages-artifact)
- [ ] 配置 GitHub Pages 部署步驟 (deploy-pages action)
- [ ] 設定環境變數 CONTENT_REPO 處理
- [ ] 配置 concurrency 控制避免多重部署衝突

## 測試方式

### 檔案驗證
- 檢查 `docusaurus/.github/workflows/deploy.yml` 檔案是否存在
- 驗證檔案內容包含 repository_dispatch 觸發機制
- 確認包含正確的權限設定 (contents: read, pages: write, id-token: write)
- 驗證環境變數 CONTENT_REPO 設定正確

### 語法驗證
執行以下指令驗證 YAML 語法：
```bash
cd docusaurus
python -c "import yaml; print('YAML syntax valid') if yaml.safe_load(open('.github/workflows/deploy.yml')) else print('YAML syntax error')"
```

### 工作流程結構驗證
檢查工作流程包含以下必要元素：
- `on.repository_dispatch.types: [content-updated]`
- `permissions` 區塊設定
- `build` 與 `deploy` 兩個主要工作
- 正確的 GitHub Actions 使用版本 (@v4, @v3)

### 本地建置測試
建立測試內容並執行本地建置：
```bash
cd docusaurus
# 模擬內容檢出
# content 資料夾已經存在
# mkdir -p content
echo "測試內容" > content/test.md
# 執行建置測試
npm ci
npm run build
# 檢查建置結果
ls -la build/
```
